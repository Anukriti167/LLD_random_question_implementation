# Splitwise — LLD

## Requirements

1. Users should be able to create and participate in groups.

2. A group can have multiple users.

3. Users should be able to add expenses within a group.

4. Each expense should contain:
   - Payer
   - Total amount
   - Participants
   - Split information

5. The system should support the following types of expense splits:
   - Equal split
   - Exact amount split
   - Percentage split

6. For an equal split, the expense should be divided equally among the participants.

7. For an exact split, the user should specify the exact amount owed by each participant.

8. For a percentage split, the user should specify the percentage owed by each participant.

9. The system should calculate the balances between users based on their expenses and splits.

10. A user should be able to see how much they owe another user and how much another user owes them.

11. Users should be able to settle their balances.

12. The system should support multiple expenses within a group.

13. The system should use a single currency.

14. Partial settlements are not required.

15. User authentication is not required.

16. Persistent database storage is not required.
